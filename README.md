# 🐾 PawTrack - Stray Animal Management System

A comprehensive full-stack web application designed to manage and track stray animals efficiently, improving animal welfare and community safety through modern technology.

---

## 🚀 Tech Stack

* **Frontend:** React.js, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Deployment:** Vercel (Frontend)

---

## ✨ Key Features

* **QR Code Tracking:** Easily track individual animals using unique QR codes attached to collars.
* **AI Identification:** Smart features for recognizing and managing animal profiles.
* **Medical History Logs:** Maintain and update vaccination records, treatments, and health statuses.
* **Hotspot Mapping:** Visualize stray animal concentrations and incident zones using integrated maps.
* **Adoption Management:** Streamline the adoption process by connecting rescues with verified adopters.

## 🛠️ Getting Started Locally

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
  git clone `https://github.com/chinthakahin/PawTrack.git`

Setup Backend:

Navigate to the backend folder and install dependencies:

Bash

Start the server:

Bash
npm start
Setup Frontend:

Navigate to the frontend folder and install dependencies:

Bash
cd animal-tracking-frontend
npm install

Start the React development server:

Bash
npm run dev
